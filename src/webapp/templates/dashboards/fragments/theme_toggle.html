{# Light/dark theme toggle. One definition, three shells: the desktop utility menu and the mobile offcanvas drawer (both in dashboards/base.html), and auth/login.html — which is a separate shell and would otherwise be easy to forget. Behavior lives in static/js/theme-toggle.js, keyed off the `data-theme-toggle` attribute rather than an id, precisely so more than one copy can be on the page at once. That script also keeps every copy's icon, title and aria-pressed in sync, so this macro only has to render a sensible *initial* state — it is passed `theme` from the context processor, the same value already on . External JS, not an inline handler: tests/unit/test_template_csp_lint.py forbids on*= attributes, and correctly so — the CSP is nonce-free by design. Args: theme: 'light' | 'dark' — the CURRENT theme. labeled: show a text label beside the icon (drawer / login), or icon-only (desktop navbar, where space is tight). classes: extra classes for the control. #} {% macro theme_toggle(theme, labelled=false, classes='') %} {%- set next = 'light' if theme == 'dark' else 'dark' -%} {%- set label = 'Switch to dark mode' if next == 'dark' else 'Switch to light mode' -%} {% endmacro %}
